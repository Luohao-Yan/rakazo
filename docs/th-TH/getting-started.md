# เริ่มต้นใช้งาน

AgentForge ให้ bot AI ที่ทำงานต่อเนื่อง แต่ละตัวมีแชท ความจำ routine และคอมพิวเตอร์ของตัวเอง และทำงานต่อบนเว็บ เดสก์ท็อป และมือถือ

## เริ่มใช้ bot ตัวแรก

1. ลงชื่อเข้าใช้ที่ instance ของคุณ หลังติดตั้ง self-host เปิด [http://127.0.0.1:5173](http://127.0.0.1:5173) วิธีติดตั้งอยู่ที่ [self-host](./self-host.md)
2. เมื่อเริ่มต้นใช้งานด้วยบัญชีใหม่ AgentForge จะสร้าง bot ตัวแรกชื่อ **Chief** ให้ บนเว็บและเดสก์ท็อป
   แชทของ Chief จะเปิดโดยอัตโนมัติ ส่วนบนมือถือให้แตะ **Chief** ในรายการ bot หาก Space ที่ใช้อยู่
   ยังไม่มี bot ให้เลือก **New bot**
3. บอกงานของ bot ด้วยภาษาธรรมดา bot จะถามสิ่งที่ยังต้องการ

ดูเพิ่มที่ [Bot และแชท](./bots-and-chats.md)

## เชื่อมแอป

bot ทำงานในแอปที่คุณใช้อยู่แล้ว: Gmail, Slack, Notion, GitHub และ
[อีกกว่า 1,400 แอป](/integrations/) ขอให้ bot เชื่อมแอปหนึ่ง แล้วอนุมัติการลงชื่อเข้าใช้ที่ bot ส่งมา ดู
[เชื่อมแอป](./integrations.md)

## ตั้งเวลาทำงาน

ขอ routine เช่น "ทุกวันทำการ 8 โมงเช้า สรุปกล่องจดหมายของฉัน" bot รัน routine บนคอมพิวเตอร์ของตัวเอง
แล้วรายงานกลับในแชทเดิม ดู [Routines](./routines.md)

## กำหนดว่าทำอะไรได้เอง

เลือกว่า bot ต้องถามก่อนลงมือหรือไม่ใน [การอนุมัติ](./approvals.md)
